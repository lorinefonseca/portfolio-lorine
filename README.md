# Portfólio Lorine — edição scrapbook

Site estático responsivo em HTML, CSS e JavaScript, pronto para publicar no GitHub e na Vercel.

## Como abrir
Abra `index.html` no navegador.

## Como publicar
1. Crie um repositório no GitHub e envie `index.html`, `styles.css` e `script.js` na raiz.
2. Na Vercel, clique em Add New > Project, importe o repositório e clique em Deploy.
3. O site não precisa de build, framework ou instalação.

## Personalizar
- Edite os textos no `index.html`.
- Ajuste a paleta nas variáveis `:root` no início do `styles.css`.
- Substitua as capas demonstrativas dos projetos por trabalhos reais.
- Atualize o link genérico do LinkedIn no rodapé para o seu perfil.
- As colagens são feitas em CSS e emojis; não dependem de imagens externas. As fontes do Google Fonts usam internet, com fontes locais de reserva.
